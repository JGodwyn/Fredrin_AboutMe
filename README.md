# AboutMe

Created with [Fredrin](https://fredrin.com).

This project runs on local git. It has no remote, and it does not need one —
branches, worktrees, diffs and merges are all local.

## Adding a page

`template/` is a copy of the live About page on PortfolioWebsite, layout and
content as they are. To start a page, copy the folder, rename it and swap in
your text. Drop the `noindex` line once it is a public page. The comments in the
file say how to add sections, list items and experience rows.
